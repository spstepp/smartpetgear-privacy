Privacy Policy

PetGearPinBot — Last updated: May 18, 2026

This privacy policy applies to PetGearPinBot ("App"), which uses the Pinterest API to publish pins to the MySmartPetGear Pinterest account at pinterest.com/MySmartPetGear.

1. Data Collected

The App does not collect, store, or share any personal data from Pinterest users. The App is used solely by its owner to post content to a single Pinterest account.

2. Pinterest API Use

The App accesses the Pinterest API exclusively to create and publish pins on the owner's Pinterest account. No data is read from or shared with third parties.

3. Data Storage

Access tokens used to authenticate with the Pinterest API are stored locally on the owner's private server and are never transmitted to or shared with any third party.

4. Third-Party Sharing

No user data, Pinterest account data, or API credentials are sold, shared, or disclosed to any third party.
